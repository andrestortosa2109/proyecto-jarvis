## Método

1. Cada concepto nuevo → mini-ejemplo que CORRE, no prosa
2. Anotar las sorpresas ("esto en MATLAB era distinto porque...") — ahí está el aprendizaje
3. Commit de apuntes al final de cada sesión de estudio
4. Repaso: ejecutar los archivos viejos e intentar predecir la salida antes de verla
